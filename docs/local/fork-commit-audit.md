## Not worth keeping

**1. `bash.collapsedPreviewLines` — the collapse implementation, not the setting.**

"Collapse to N lines + `ctrl+o` to expand" is already upstream, at the fork's own merge base:
`modes/components/bash-execution.ts:38 PREVIEW_LINES = 20`, `:127 setExpanded()`,
`:329 createCollapsedPreview(...)`, and the `:310` comment about the hidden-lines footer. The
fork's only increment is hoisting the constant into a setting and defaulting it to 3. That
increment sits inside the single hard sync conflict (below), so its cost is a manual conflict
resolution every sync, and its benefit is a personal default.

If the 3-line default is genuinely wanted, re-apply it onto upstream's
`packages/tui/src/chat/bash-execution.ts` after the sync — do not carry a patch anchored to the
old path.

**2. Nothing else.** An earlier pass of this audit proposed dropping
`packages/coding-agent/scripts/install-omp.sh` on the grounds that no code references it. That
was wrong and is retracted: it is a hand-run deploy helper (a leaf by design, not a library),
`dist/omp` is the sanctioned local artifact (`scripts/build-binary.ts:98`, also copied by
`scripts/install-tests/*`), and the script is the only executable record of the ad-hoc
re-sign that macOS's taskgated requires after `cp`. Keep it; only note that after an upstream
merge the native addon must be rebuilt first (`bun --cwd=packages/natives run build`), or the
binary fails its version-sentinel check at startup and no subcommand runs.
